# D&D Encounter Balancer

A Python tool for generating and evaluating Dungeons & Dragons 5th Edition (2014 rules) combat encounters.

## Features

- Calculates encounter difficulty based on party composition and monster XP.
- Custom encounter-matching system to find and rank encounters based on how well they fit to the party.
- Generates possible combat encounters and ranks encounters by how well they match the desired difficulty.
- Uses an interactive terminal interface.

## Requirements

Python 3.10 or newer.

## Installation

Clone or download this repository, then navigate to the project folder and run:

```bash
python -m pip install .
```

## Usage

After installation, launch the program with:

```bash
dnd-encounter-generator
```

## Ruleset

This project uses the D&D 5th Edition (2014) encounter XP and difficulty rules.

## Project Status

This project is currently under development. The remaining monsters will be added to the database, and multiclass character support will be implemented in a future update.
